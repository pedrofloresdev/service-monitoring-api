From specs/$1/spec.md and specs/$1/plan.md, write specs/$1/tasks.md in the sdd skill format:
- Small tasks (max 20-30 min each), in dependency order.
- Each with the RF it covers and a verifiable "Done when:" line.
- Checkboxes.
- Aim for at most 10; if more, propose splitting the spec.
Do not write code.
